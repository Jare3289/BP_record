# 🩺 ระบบบันทึกความดันโลหิต (BP Record)

เว็บแอปพลิเคชัน PHP + MySQL สำหรับบันทึกและติดตามค่าความดันโลหิต
วัดตอนเช้าและก่อนนอน เวลาละ 2 ครั้ง คำนวณค่าเฉลี่ยรายวันและแปลผลอัตโนมัติ

## คุณสมบัติ

- บันทึกค่า **ตอนเช้า** และ **ก่อนนอน** อย่างละ 2 ครั้ง (ความดันบน / ล่าง / ชีพจร)
- คำนวณ **ค่าเฉลี่ยรายวัน** อัตโนมัติ
- **แปลผล** ระดับความดันโลหิตตามเกณฑ์ ACC/AHA (ปกติ / สูงเล็กน้อย / ระยะที่ 1 / ระยะที่ 2 / วิกฤต)
- การ์ดสรุป สูงสุด / ต่ำสุด / เฉลี่ย
- เพิ่ม / แก้ไข / ลบ ข้อมูลได้
- บันทึกซ้ำวันเดิมจะอัปเดตทับให้ (1 วัน = 1 แถว)

## การติดตั้ง

### 1. เตรียมฐานข้อมูล

```bash
mysql -u root -p < schema.sql
```

จะได้ฐานข้อมูล `bp_record` และตาราง `bp_readings`

### 2. ตั้งค่าการเชื่อมต่อ

แก้ไขไฟล์ `includes/config.php` หรือกำหนดผ่าน environment variable:

```
DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASS
```

### 3. รันเซิร์ฟเวอร์

ใช้ built-in server ของ PHP (สำหรับทดสอบ):

```bash
php -S localhost:8000
```

เปิดเบราว์เซอร์ที่ http://localhost:8000

หรือวางไฟล์ทั้งหมดไว้ใน DocumentRoot ของ Apache/Nginx ที่รองรับ PHP

## เกณฑ์การแปลผล (ACC/AHA)

| ระดับ | ความดันบน (mmHg) | ความดันล่าง (mmHg) |
|-------|------------------|--------------------|
| ปกติ | < 120 | และ < 80 |
| สูงเล็กน้อย | 120–129 | และ < 80 |
| ระยะที่ 1 | 130–139 | หรือ 80–89 |
| ระยะที่ 2 | ≥ 140 | หรือ ≥ 90 |
| วิกฤต | ≥ 180 | หรือ ≥ 120 |

## โครงสร้างไฟล์

```
BP_record/
├── index.php              # หน้าหลัก: สรุป + ฟอร์ม + ตาราง
├── save.php               # จัดการเพิ่ม/แก้ไข/ลบ
├── schema.sql             # โครงสร้างฐานข้อมูล
├── includes/
│   ├── config.php         # การเชื่อมต่อฐานข้อมูล (PDO)
│   └── functions.php      # คำนวณค่าเฉลี่ย + แปลผล
└── assets/
    ├── style.css
    └── app.js
```

> ⚠️ ข้อมูลนี้ใช้เพื่อการติดตามเบื้องต้น ไม่ทดแทนคำวินิจฉัยของแพทย์
